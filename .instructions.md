# Provasign — Mandatory Workflow Rules

## Prism Context Delivery (ENFORCE STRICTLY)

**This project uses Prism (MCP) for token-optimized context delivery.** All code discovery MUST follow this workflow:

### Rule 1: Always start with prism_query
- **FIRST action** for any code search, symbol lookup, or context-gathering task
- Call `prism_query` with the task description
- Do NOT use file_search, grep_search, or read_file until after prism_query

Example:
```
prism_query(task: "Find Java language support in parser")
// Returns ranked symbols with full context
```

### Rule 2: Use Prism search tools, never grep/ripgrep
- `prism_search(query: "symbol_name")` → find symbols by name
- `prism_lookup(name: "fully.qualified.Name")` → full source
- Never use `grep_search` for symbol discovery

### Rule 3: Use prism_read for file content, never read_file
- `prism_read(file: "path/to/file.go")` → session-aware compression
- Saves 35–92% tokens vs raw read_file
- Use read_file ONLY if prism_read returns empty

### Rule 4: Index at session start
- Call `prism_index` once per session after large file changes
- Delta indexing is automatic; don't re-index every step

### Rule 5: If Prism returns empty, retry with index first
- Do not immediately fall back to grep/read_file
- Run `prism_index` for the workspace root, then retry prism_search/prism_query
- Only use non-Prism fallback if second attempt still empty

## Prism Tool Priority

| Task | Use This | NOT This |
|------|----------|----------|
| Manual context gather | `prism_query` | `file_search` + multiple reads |
| Find symbol by name | `prism_search` | `grep_search` |
| Read file content | `prism_read` | `read_file` |
| Symbol definition | `prism_lookup` | manual file reading |
| Test relevant to symbol | `grove_tests` | manual search |

## Why This Matters

- **Prism saves ~70% context window** through progressive disclosure (full → signature → reference)
- **Session deduplication** prevents re-sending the same symbol multiple times
- **5-signal ranking** (graph distance, similarity, recency, test relevance, edit frequency) surfaces the right code
- Token budget for this workspace: **194 KB** — Prism tools keep us under this

## Consequences of Not Following This

- Wasted tokens on redundant context
- Missing symbol relationships from Grove graph
- Slower task completion (more context gathering steps needed)
- Risk of context window overflow
